# Movie Website

Веб-приложение для поиска фильмов с личным кабинетом и списком избранного. Данные о фильмах берутся из API Кинопоиска, а авторизация и избранное хранятся в Supabase.

## Возможности

- Поиск фильмов по названию и просмотр страницы фильма.
- Регистрация и вход по email и паролю, с уникальным ником.
- Личный кабинет: ник, дата регистрации, дата последнего посещения, список избранных фильмов.
- Добавление фильмов в избранное. Для гостя фильм запоминается, а после входа добавляется автоматически.
- Мгновенный отклик интерфейса (оптимистичные обновления) и кэширование запросов.
- Понятные сообщения об ошибках: нет сети, сервер недоступен, превышен лимит запросов.
- Отлов ошибок отрисовки через ErrorBoundary с возможностью повторить.

## Технологии

**Клиент**
- React 19, TypeScript, Vite
- React Router
- TanStack Query (кэш, мутации, оптимистичные обновления)
- Zustand (состояние авторизации и интерфейса)
- Zod (валидация данных API и форм)
- MUI, SCSS-модули
- oxlint

**Бэкенд**
- Supabase: Auth, PostgreSQL, Row Level Security
- Cloudflare Worker: прокси к API Кинопоиска. Он прячет ключ API, ограничивает CORS по разрешённым адресам, кэширует ответы и ограничивает частоту запросов.
